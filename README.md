# CUT BOARD — 絵コンテアプリ（GitHub Pages対応）

カメラワーク標準24種類を維持しつつ、カスタム演出を **アプリ内** と **コード** の両方から管理できる静的Webアプリです。

## ファイル
- `index.html` — アプリ本体
- `custom-cameras.js` — GitHubで共有する共通カスタム演出一覧
- `manifest.webmanifest` — PWA用の基本情報
- `firestore.rules` — ログインユーザーごとに保存先を分けるFirestoreルール
- `.nojekyll` — GitHub Pagesで静的ファイルを公開するための設定
- `README.md` — この説明

## カスタム演出を追加する方法

### A. アプリ内で追加（コード不要）
1. アプリ左側の「カスタム演出を追加」へ。
2. 名前、英語名、説明を入力して登録。
3. カットを選んで、カメラワーク欄から登録した演出を選ぶ。

この方法で追加した演出は「自分の演出リスト」に保存され、新しいプロジェクトでも再利用できます。リストは同じブラウザ内の `localStorage` に保存されます。プロジェクトを新規作成しても演出リストは残ります。JSONバックアップには個人用演出リストも含まれるため、別端末に移す場合は書き出したJSONを読み込んでください。

### B. GitHubのコードで追加（全利用者共通）
`custom-cameras.js` を編集し、配列に次のような項目を追加してコミットします。

```js
window.CUTBOARD_CUSTOM_CAMERAS = [
  {
    id: "G01",
    name: "スライダー移動",
    english: "Slider move",
    description: "スライダーで水平に移動する"
  }
];
```

- `id` は `G01`、`G02` のように重複しないIDにしてください。
- `name` は必須です。`english` と `description` は任意です。
- GitHub上でファイルを編集してコミットすると、公開サイトにも反映されます。
- コードで追加した演出はサイト利用者全員に表示されます。個人のプロジェクトだけに保存したい場合はアプリ内追加を使ってください。

## GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作成（例：`cut-board`）。
2. このフォルダの中身をリポジトリのルートへアップロードします（ZIPファイルそのものではなく、展開した中身）。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment → Source** で **Deploy from a branch** を選択。
5. Branch を `main`、フォルダを `/(root)` にして **Save**。
6. Pages画面に表示されるURLを開きます。公開反映まで少し時間がかかることがあります。

GitHub公式ガイド: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## 保存・ログイン・同期
プロジェクトは引き続きブラウザの `localStorage` に保存されます。ログイン後もクラウドへの読み込みや移行は自動実行されません。アカウント設定から「このローカルプロジェクトをクラウドに新規保存」を選ぶとユーザー専用の保存先を作り、以降の編集を同期します。既存プロジェクトの読み込みは、選択後に確認してから行います。複数端末で同時に変更された場合、古い版からの自動上書きを止めて画面に知らせます。

Firebase AuthenticationでGoogleとメールアドレス／パスワードを有効にし、Authenticationの承認済みドメインに `thunder923.github.io` を追加してください。Firestoreの「ルール」に [`firestore.rules`](firestore.rules) の内容を貼り付けて公開します。ルールを公開しないとクラウドの読み書きは拒否されます。このアプリはFirebase Web SDKをCDNから読み込み、Firestoreにユーザー別のプロジェクト文書を保存します。Firebase Storageは使用しません。

メールアドレスで新規登録すると、Firebaseから確認メールが送信されます。リンクを開いて確認が完了するまで、メール／パスワードアカウントのクラウド機能は使えません。設定画面から確認メールの再送と確認状態の更新ができます。ログイン画面の「パスワードを再設定」から再設定メールも送信できます。送信メールの件名や本文はFirebase ConsoleのAuthentication → Templatesで編集できます。

Firestoreの1文書上限を超えないよう、アプリはプロジェクトJSONが約850 KiBを超える場合、クラウド保存を止めて説明を表示します。画像や描画を含むプロジェクトはこの上限に達しやすいため、JSONバックアップも継続して利用してください。Sparkプランの範囲内での利用を想定し、有料プランへの切り替えは行いません。実際の利用量はFirebase Consoleで確認してください。

## 3Dシーンスタジオ

各カットの「♟ 3Dシーン」から実際の3D空間を開けます。視点を回転・ズームし、人物や椅子・ベンチ・木のモデルを配置できます。オブジェクトはギズモまたは数値入力で位置を調整し、移動・回転・拡大縮小ができます。撮影カメラの位置、注視点、画角を設定し、カメラ視点の画像をカットへ保存します。人物ポーズプリセットと関節調整も引き続き使えます。配置データはカットおよびJSONバックアップに保存されます。

3D描画はThree.jsのCDN読み込みを使います。人物と小道具は基本形状を組み合わせた軽量モデルなので、WebGL対応ブラウザとインターネット接続が必要です。外部モデル配布サービスや有料アセットは使用しません。


## 画像・PDFの取り込みと共有
- サイドバーから画像/PDFを選択すると、画像は1カット、PDFは各ページを画像化してカットとして追加します（PDF読み込みはPDF.js CDNへの接続が必要です）。
- 作品名・制作日/受領日・各カットのシーン名で整理できます。
- 「印刷 / PDF保存」からブラウザの印刷画面でPDF保存できます。
- 「画像で共有（PNG）」はカットごとのPNGを書き出します。iPhoneでは複数ダウンロードの許可を求められる場合があります。
