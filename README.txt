CUT BOARD 更新版

追加内容:
- カット番号を自由入力（重複可）
- シーン番号を自由入力（重複可）
- カット複製時は番号やシーン情報もそのまま複製
- アカウント設定欄（表示名をこの端末に保存）

重要:
Google/Appleログインおよびクラウド同期はまだ有効ではありません。
Firebaseプロジェクトの作成、認証プロバイダ設定、Firestore/Storage設定とセキュリティルールが必要です。

GitHub Pages更新方法:
1. 既存のindex.htmlをバックアップ
2. このZIPのindex.htmlをGitHubリポジトリのindex.htmlに置き換える
3. Commit changes後、GitHub Pagesを再読み込み
4. 念のため、既存データを先にJSON書き出しでバックアップしてください。
